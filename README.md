# INVINCIBLE: SIMULATION

A turn-based superhero battler set in the Invincible universe, with a Cyber GUI theme and deliberately scrappy hand-drawn sprites.

**Live game:** https://sycatrandy-alt.github.io/invincible-simulation/

## Stack
- Pure HTML / CSS / vanilla JS
- No build step — just open `index.html`
- GitHub Pages auto-deploys on push to `main`

## Play locally
Open `index.html` in any modern browser.

## Updating
```bash
git add -A
git commit -m "your message"
git push
```
Pages picks up the change in ~1–5 minutes.
