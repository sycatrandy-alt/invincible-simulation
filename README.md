# PANCAKE BUNNY · RPG

A breakfast-themed turn-based RPG with Cyber GUI styling.

**Live game:** https://sycatrandy-alt.github.io/invincible-simulation/

## Cast
- **Pancake Bunny** — leader, electrical manipulation
- **Waffle Rabbit** — glass cannon, power of explosions
- **Butta Dawg** — healer, healing factor + healing magic

## Stack
- Pure HTML / CSS / vanilla JS
- No build step — just open `index.html`
- GitHub Pages auto-deploys on push to `main`

## Updating
```bash
git add -A
git commit -m "your message"
git push
```
Pages picks up the change in ~1–5 minutes.
